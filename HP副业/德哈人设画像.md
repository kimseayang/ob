# 德哈人设画像 · 跨平台落盘

> 起号底层素材库。平台内核一致、调性分叉；写笔记 / 出图 / 写文案前先翻这一份定位。

---

## 一、跨平台内核（通用人设骨架）

| 维度 | 德拉科（Draco Malfoy） | 哈利（Harry Potter） |
|---|---|---|
| **身份符号** | 铂金少爷 / 斯莱特林继承人 / 纯血家族长子 | 救世主 / 格兰芬多 / 大难不死的男孩 |
| **核心标签** | 傲娇、嘴硬心软、颜值天花板、被家族束缚 | 美强惨、孤勇者、抗争宿命 |
| **反差萌点** | 表面冷酷 vs 私下细腻；黑魔王印记下的少年恐惧 | 救世主光环下仍是会怕黑、会犯轴的少年 |
| **关系张力** | 宿敌 → 恋人、学院对立（狮 vs 蛇）、身份悬殊 | 同上，且两人是"镜面"——一个被家族定义、一个被预言定义 |
| **改编空间** | 黑化 / 洗白 / 重生 / 追妻 / 圣芒戈院长线都吃 | 美强惨放大器，受方 / 攻方都能立 |

**关系线母题**：宿敌转恋人、学院对立羁绊、宿命感、纸短情长。

**画图/出稿铁律**：
- 不还原具体情节（原作两人戏份少），靠"人设符号 + 张力构图"出图。
- 别画成纯反派，德拉科必须有"被裹挟的少年感"，否则流失女性受众共情。
- 不生成真人演员脸、不碰官方剧照 / logo（版权红线，见 [[方向思路]] 第六节）。

## 二、流量构图库（跨平台通用，直接喂 AI 出图）

最吃流量的 5 类画面（已验证）：
1. **两人对视 / 对峙 / 背靠背** — 经典 CP 视觉，互动感强。
2. **纸鹤传信** — 德哈标志性符号物（高辨识度、低版权风险）。
3. **魔杖交锋** — 神锋无影 vs 阿瓦达 / 缴械咒，光效对比拉满。
4. **学院色对比** — 斯莱特林墨绿+银 vs 格兰芬多猩红+金，色块即故事。
5. **圣诞 / 雪夜 / 霍格沃茨长廊** — 应季氛围感，12 月流量峰值主图。

风格锁定建议：**主 1 套 + 副 1 套** 做辨识度（主推「暗金奢华斯莱特林」 + 「暗夜纸鹤水墨」二选一）。

## 三、平台分叉画像

### 3.1 小红书 🟢 主阵地（最优先起号）

**用户画像**：18–30 岁女性 HP 粉 / 颜值控 / 嗑糖党 / 学生 & 上班族。
**内容调性**：颜值拉郎、嗑糖图文、学院色、Q 版可爱向、二创壁纸。
**主打产品**：壁纸 / 亚克力立牌 / 拼豆图纸（这三类在小红书有现成货架）。
**爆款选题**：
- "德哈壁纸｜暗金斯莱特林 × 格兰芬多红"
- "德拉科 Q 版立牌｜这谁顶得住"
- "霍格沃茨情侣头像｜狮蛇对视"
- "拼豆图纸 PDF｜德拉科像素版"
**出图风格建议**：精致、华丽、可可爱爱、Q 版 / 半 Q 半写实；学院色饱和度高。
**避坑**：不要长剧情图、不要暗黑人设图（小红书调性偏甜）、标题党但不要擦边。

### 3.2 抖音 🟡 视频主场

**用户画像**：HP 粉 + 路人颜值党 + 剪辑向受众，男女比相对小红书均衡。
**内容调性**：名场面剪辑、张力拉满、节奏紧凑、配 BGM。
**头部标杆**：德哈头部号单视频播放量 **1.2 亿**（量级参考）。
**吃流量的剪辑母题**：
- 「走吧，咱回家」类台词混剪
- 神锋无影 vs 阿瓦达 对峙剪辑
- 纸鹤传信慢镜头
- 打情骂俏大会 / 课堂传纸条片段
**主打产品**：拼豆成品过程短视频、立牌开箱 / 摆阵、壁纸轮播、手机壳展示。
**出图风格建议**：高对比、电影感、暗调光影；首帧要有"停顿感"便于停留。
**避坑**：BGM 版权、搬运剧版 / 电影原片段（哪怕 3 秒也算违规）。

### 3.3 Lofter 🔵 文学/设定深度阵地

**用户画像**：深度哈粉 / 同人写手 / 设定党 / 长情读者，付费意愿高。
**内容调性**：深度文学二设、ABO / 第八年 / 重生 / 破镜重圆、考据细节。
**高频二设母题（直接可当选题）**：
- **第八年**（战后重聚，霍格沃茨复课）
- **重生德**（重生回一年级改写命运）
- **圣芒戈院长德 × 傲罗部长哈**（成年职业线）
- **追妻火葬场 / 破镜重圆**
- **互攻 / 攻受转换**
**主打产品**：追剧手帐 PDF（带二设 + 剧版时间线）、设定集深度内容、长图壁纸（带文案）。
**出图风格建议**：古典、英伦、霍格沃茨质感；带拉丁文 / 法文 / 古英文短句的留白款。
**避坑**：不要纯甜无脑、要有人设张力；不要把德拉科写成纯反派（深度受众更吃"被裹挟感"）。

## 四、增量信号（重点关注）

**2025 年爆款 CP：德赫（Draco × Hermione）**
- 《Alchemised》售出 **300 万美元**影视版权（业内顶级二创变现标杆）。
- TikTok 同名话题浏览 **4.7 亿**。
- 同人热度断崖式上涨（具体数字待 9 月底补 AO3 检索）。

**结论**：德拉科自带全 CP 流量红利，副线可双吃。
- 主线：**德哈**（最大流量 + 女性受众精准）。
- 副线：**德赫**（变现天花板高 + 影视改编信号强）。
- 两条线都做"德拉科核心人设"，文案 / 出图可共用 70% 素材。

## 五、出稿 Checklist（取用时自检）

- [ ] 内核对得上：德拉科有没有"被裹挟的少年感"？不是纯反派？
- [ ] 关系张力够不够：有没有"宿敌 / 对峙 / 镜面"任一符号？
- [ ] 平台调性对不对：小红书偏甜、抖音要张力、Lofter 要深度。
- [ ] 流量构图命中：是否用了 5 类母题之一？
- [ ] 风格统一：是否锁在 1–2 套主风格内？
- [ ] 版权合规：是否避开了真人脸 / 官方剧照 / logo？
