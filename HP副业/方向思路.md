# HP 剧版副业 · 方向思路总览

> 一句话：用 2026.12.25 HBO 剧版首播的确定性流量红利，以「德拉科主、哈利辅」定位做二创周边 / 数字产品变现，不压货、先测款。

## 一、目标与时机
- HBO 剧版《哈利·波特与魔法石》定档 **2026.12.25** 圣诞全球首播；剧版特意拓展德拉科家庭线（新卡司 Lox Pratt 饰 Draco）。
- 现在 9 月是预热期，应在首播前把账号 + 设计稿跑通，卡流量峰值变现。

## 二、定位（兴趣 × 流量完全重合）
- 德拉科主、哈利辅 = **德哈（HP 第一 CP）**：流量最大、女性受众为主，匹配小红书哈粉。
- 写过的小天狼星同人 = **犬狼（HP 第二 CP）**：可双线铺，不浪费积累。
- 不碰：斯内普、邓布利多向（个人偏好）。

## 三、选品方向
- **实物周边**（AI 生图 + 一件代发，不压货）：手机壳、亚克力立牌。
- **数字产品**（零库存，主推）：壁纸、头像、Obsidian 霍格沃茨主题、剧版追剧手帐 PDF。
- **图纸类**（数字 + 材料包代发，重点验证）：拼豆图纸 PDF + 拼豆材料包。

## 四、流量依据（全网热度，2026-09-08 检索）
- 角色：书里提及量德拉科仅第 9，但**粉丝流量 / 同人热度顶流** → 追流量维度而非戏份维度。
- CP（AO3 单 CP 作品数）：德哈 36882（断层第一，≈犬狼 3 倍）> 犬狼 12164 > 斯哈 10176 > 汤哈 2202 / 思蝎 2174 / GGAD 2044 / SNUPIN 2008 / 哈罗 1388。
- 拼豆 + 影视 IP 已被验证为爆发模式（如《永夜星河》），HP 剧版是确定性顶级 IP 热点。

## 五、执行节奏
- 9–10 月：起号 + 出德拉科 / 德哈设计稿（AI 生图）+ 对接材料包代发。
- 11 月：剧版热度爬升，密集发笔记测款。
- 12.25 首播：流量峰值，图纸 + 材料包 + 数字产品集中变现。
- 圣诞：圣诞限定 HP 拼豆 / 壁纸应季。

## 六、版权纪律（红线）
- 原创二创风、不生成真人演员脸、不碰官方剧照 / logo。
- 电商上架比内容敏感，先测款、小批预售，绝不压货。

## 七、资源
